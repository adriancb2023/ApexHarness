# ApexHarness

Harness de IA tipo Orca/ADE: GUI web como centro de control de OpenCode (sesiones, multi-proyecto, debate backend/frontend), con Kanban automático por agentes y memoria Engram.

## Agent skills

### Issue tracker

Local markdown en `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five roles, as `Status:` lines. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context (`GLOSSARY.md` + `docs/adr/` en root, aún por crear). See `docs/agents/domain.md`.
